# Deprecated Skills

Retired or superseded skills are kept here for reference. They are excluded from installer discovery because archived skill files are named `ARCHIVED-SKILL.md`, not `SKILL.md`.

- `local-*` folders are pre-modernization local versions replaced by active Matt-baseline skills.
- `to-prd` and `to-issues` were renamed to `to-spec` and `to-tickets` to match Matt Pocock's baseline.
- Other folders are older local workflows retained because they may still explain previous project habits.
