# write-like-me

Rewrites text to sound direct, practical, and human by removing AI polish, corporate phrasing, over-explaining, empty balance, and unnatural symmetry—without faking typos or inventing facts. Use when the user says sound less AI, un-AI this, write like me, more natural, sound human, less corporate, rewrite in my style, or like something I would send.

## Quickstart

Install this skill with the repository installer:

```bash
npx skills@latest add maccalsa/skills --skill=write-like-me
```

For a local checkout, run the maintainer linker from the repository root:

```bash
./scripts/link-skills.sh
```
