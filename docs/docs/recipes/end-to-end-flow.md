# End-to-end flow

Use this when an idea needs to become implementation work.

1. Run `/setup-agent-skills` once in the target repo.
2. Run `/grill-with-docs` to sharpen the idea and update domain docs when useful.
3. Use `/prototype` only when a runnable answer would settle an open question.
4. Run `/to-spec` when the conversation has enough context to become a spec.
5. Run `/to-tickets` to split the spec into tracer-bullet tickets.
6. Start a fresh session per ticket and run `/implement`.
7. Finish with `/code-review` or `/branch-diff-code-review` depending on the review output you need.
